The re-check agents found three more:

- **The chart render test runs in no CI workflow.** The worker split, the disruption protection, the metrics scrape and the new alert rules have never been rendered by helm. The commit message of `caa92a660` says the test runs in CI; that is wrong.
- **The queue alerts read one pipeline-wide value.** The short-class alert fires whenever any long video has waited 10 minutes.
- **The length cap is still not enforced early.** Neither client sends `duration_ms` at upload init, so a file over 4 hours uploads in full before it is refused.
