# Cloud agent brief — POSTTUBE production-readiness audit (YouTube reference)

Read `docs/production-readiness/agents/00_COMMON_RULES.md` first. Audit only; no code changes. Output: `docs/production-readiness/POSTTUBE_AUDIT.md` + `POSTTUBE_AUDIT_LOG.md` on branch `audit/posttube-production-readiness`.

## Scope checklist (every item becomes a row in your feature matrix)
**Video management:** long-form upload (YouTube allows up to 12 h / very large files — state what the code allows and whether 12 h is feasible); resumable chunked upload for very large files (100 GB+ target — state current limits); processing workflow upload → transcode → thumbnail → publish; metadata (title, description, category, tags, thumbnail, visibility public/unlisted/private); validation (format, codec, duration, resolution, aspect ratio); processing failures (retry, failure notification, job monitoring).
**Channels & creators:** channel creation (profile, art/banner, description, subscriber count, handle); organisation (playlists, series, collections); channel analytics (views, subscriber growth, watch-time trends); monetisation (future — note only).
**Playback:** ABR HLS (360p–1080p; 4K state); progress save and resume; watch history with pause/hide and clear; captions (multiple languages) and audio tracks; quality menu; playback recovery.
**Engagement & discovery:** threaded comments, pinned/hearted comments, moderation; like/dislike (dislike private); view counting; sharing (links, embed — check if embed exists), subscriptions + subscriptions feed + bell notifications for new uploads; related videos (watch history + similarity); playlists create/share/reorder; system playlists (Watch later, Liked).
**Publishing & visibility:** states processing → published → archived/deleted (restore); public/unlisted/private; scheduled publishing; edit metadata, thumbnail, visibility after publish without re-upload.
Also in this product: series auto-advance, chapters, end screens and cards, Creator Hub (library, insights, conversations, captions), RSS channel feeds, offline copies (in-app only), live-to-VOD recordings, copyright match.

## Known items to re-verify (older notes; may be stale)
- Upload → publish end to end was never exercised with a real landscape long video through the resumable path (short clips skip title/channel/category guards).
- Stall sweeper exists now (migration 021) — verify it recovers orphaned "processing" jobs and that the creator sees failure states.
- Signed-out public playback implemented via `anonymousAsEmpty` — verify end to end and that unlisted/private/members-only stay denied (including direct `/hls-seg/` and CloudFront URLs).
- Cover-frame `timestamp_ms` was a no-op; owner download served 720p, not the original; web add-to-collection position could overwrite; Android likes via `/reactions` skipped the Liked playlist; Android uploads defaulted `notify_subscribers=false`.
- `FEED_MEDIA_BASE_URL` set for qa/prod; RSS falls back to `NEXT_PUBLIC_API_BASE_URL`.

## Targets for the scaling assessment
**100K+ concurrent viewers per video, < 100 ms recommendation (related) API, 99.95% uptime.** Assess CDN cache behaviour for hot videos (segment and manifest caching, signed URL cache keys — signed query strings can destroy cache hit ratio; check whether signed cookies or path-based signing are used), origin shielding, progress-save write rate (one write per N seconds per viewer), comment hot-spot writes, subscriber fan-out for channels with 1M subscribers (job batching, push rate limits), related-videos query cost. Propose load tests (k6/vegeta) with data sizes and pass criteria.

## E2E journeys for your matrix
- Upload a 10-minute video → process → publish → set thumbnail → appears on the channel.
- Play → history saved → leave → return → resumes from the last position.
- Create playlist → add, reorder, share → works for another user (visibility respected).
- Subscribe → new upload appears in the subscriptions feed and (bell on) a notification arrives.
- Comment, pin, heart/like comments → threading and counts correct.
- Series → episodes auto-advance in order.
- Quality switching 360p/720p/1080p smooth; captions and audio-track selection.
- Unlisted reachable by link only; private owner-only; deleted not reachable; scheduled not visible before time.
- Large file resumable upload survives a network drop and resumes.
